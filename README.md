# Shenandoah Zoom Help

Static Zoom and Zoom Room help site for Shenandoah University.

## GitHub Pages

Upload all files and folders in this directory to the root of the repository. Keep `assets/` and `downloads/` intact. In the repository's Pages settings, publish from the root of the `main` branch.

The room directory is intentionally marked **Under construction** until a verified room inventory is available.
